# 固体火箭发动机实验安全
---
- 高温、高压、含能、有毒、噪声
- 常用固发燃烧室的温度：3000~4000K
- RBCC（航发）的燃烧室温度：1000～2000K
- 压强有 > 10MPa 的，也有 < 10MPa 的，超高压：100MPa（1000bar）
- 毒性要谈剂量，安全第一，保密+安全
- 出去学校做实验要怎么做

> - 实验：重复性工作，验证性
> - 试验：探索性工作，尝试性（最危险）

## 基础认知和试验体系——懂原理、知危险、明标准
- 固发的组成：燃烧室、装药、喷管、点火装置、前后封头、绝热层、推力矢量控制
- 固发的原理
    - 加电点燃的火工品（远控电信号触发点火器点燃）
    - 点火药高温燃气点燃主装药（点火的信号：）
    - 燃烧产生高温高压燃气，3500K，1～250 bar
    - 喷管：燃烧室的速度一般声速是1175,1200m/s（不能从喷管前面经过）
- 特点：反应速度快，建立压强的时间短，推进剂自带氧化剂，燃烧开始后难以中止
- 固发试验：
    - 燃烧：异质推进剂、复杂燃气环境颗粒燃烧，燃烧不稳定
    - 流动：复杂的多相流动
    - 热结构：绝热层、喉衬烧蚀
    - 发动机：推力、比冲性能测试
- 测量参数和仪器：
    - 压强
    - 温度
    - 比冲（反推）
- 六大危险源：
- 危险：漏气（内弹道异常）、发动机燃烧室、损坏测量仪器、引起爆炸、人员伤亡
- 发动机设计问题：
    - 推进剂相关参数：$r = ap^{n}$，单位是兆帕！
    - 喉径：稳态平衡压强公式、材质、烧蚀、拥堵
    - 发动机壁厚：几毫米到几十毫米
    - 安全系数：2～5
    - 壳体材质：45#钢、不锈钢、30CrMnSi等
    - 玻璃：有机玻璃也即塑料
    - 螺栓：4.8~12.8
    - 焊接工艺：存在沙眼、需打水压测试
- 实验操作问题：
    - 没有安全培训
    - 未除静电
    - 点火药包安放制作不规范
    - 安全距离不够等等
- 引发实验试验危险因素：
    - 有毒燃气
    - HCl强腐蚀、CO窒息性、NOx刺激呼吸道、试验后排气>=15min
    - 进入现场带防毒面具，喷管方向！
- 外场试车基本要求
    - 选址、警戒、防雷防静电
    - 天气条件、吊装作业、紧急叫停
- 熟悉法规标准体系
    - 法律
    - 行政法规
    - 核心行业标准
- 建立风险意识
